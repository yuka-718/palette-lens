# Palette Lens

カメラをかざすだけで、目の前の色をわかりやすい慣用色名とコーディネートのヒントに変えるアクセシビリティWebアプリです。

## できること

- スマホカメラの中央またはタップした場所から色をリアルタイム判定
- RGB値をLab色空間へ変換し、約30色の慣用色辞書から近い色名を表示
- 「明るい、オレンジ寄りのピンク」のような日常表現を表示
- 服選びに使いやすい配色とコーディネートのヒントを提案
- Web Speech APIによる日本語音声読み上げ
- 写真ファイルからの色判定
- カメラ映像と写真をサーバーへ送らず、ブラウザ内だけで処理

## 判定ロジック

選択地点の周辺ピクセルを平均化し、sRGBからLab色空間へ変換します。約30色の慣用色辞書との色差を計算して最も近い色名を選び、色名ごとに用意した日常表現と配色提案を表示します。カメラのタップ位置は次の操作まで保持され、矢印キーとEnterキーでも照準を操作できます。

## 生成AIの利用

- ChatGPT / Codex: 初期実装、コードレビュー、文章の推敲
- OpenAI Image Generation: SNS共有画像 `og.png` の制作

応募時には、使用範囲を申告し、コード・設計意図・判定ロジックを応募者自身の言葉で説明できる状態にしてください。

## GitHub Pages

`main` ブランチへのpushでGitHub Actionsが自動公開します。カメラはHTTPS環境で利用できます。

ローカルでは任意の静的ファイルサーバーで `index.html` を開いてください。
